🏠 宿舍自动签到系统

中南林业科技大学 · 平安打卡自动签到解决方案

✨ 系统简介

本系统为中南林业科技大学"平安打卡"小程序提供自动签到服务。每晚 21:00-22:20，系统自动为已注册用户完成签到，无需手动操作。

核心理念：一次性抓取 openid，终身自动签到，简单高效。

🎯 核心功能

🤖 自动签到

每晚自动为所有成员签到，每人有独特的签到时刻（21:00-22:20 分散），避免风控

🔒 隐私保护

普通用户验证姓名后只能查看自己的记录，其他用户姓名自动隐藏为"用户 X"

📊 实时看板

可视化月历显示签到状态，今日总览、7天状态条、成功/失败统计一目了然

👤 自助管理

用户可自助退出系统，管理员可管理成员、查看所有数据、设置全局开关

📱 消息通知

签到失败时自动推送通知给管理员，成功时静默记录不打扰

📈 历史追踪

完整保存所有签到历史，支持 185 天月历回溯查询

🎨 双模式设计

👥 访客模式（姓名验证）

  • ✅ 输入姓名验证身份
  • ✅ 只显示自己的签到记录
  • ✅ 其他用户姓名自动隐藏
  • ✅ 查看个人完整日历
  • ✅ 自助退出系统

👨‍💼 管理员模式（admin 登录）

  • ✅ 查看所有成员真实姓名
  • ✅ 今日签到总览统计
  • ✅ 成员管理：拉黑、删除、恢复
  • ✅ 黑名单管理
  • ✅ 已删除成员管理
  • ✅ 历史孤儿记录清理
  • ✅ 全局自动签到开关
  • ✅ 成员搜索过滤

🏗️ 技术架构

前端：Cloudflare Pages（全球 CDN 加速，自动部署）

后端：阿里云函数计算 FC（Serverless，按需计费）

存储：阿里云 OSS（对象存储，高可用）

通知：Server 酱（微信推送）

Python 3.10 原生 JavaScript 阿里云 FC Cloudflare Pages OSS 对象存储 mitmproxy

🔐 安全机制

  • 令牌认证：管理员和用户分别使用 HMAC-SHA256 签名令牌，防伪造
  • 隐私哈希：openid 通过 SHA256 转换为 member_id，前端不暴露敏感信息
  • 注册口令：采集工具使用预共享密钥 + 服务端 openid 校验双重防护
  • 黑名单机制：被拉黑用户无法注册，只能由管理员恢复
  • 软删除设计：删除保留历史记录，支持恢复，避免数据丢失

⚡ 性能优化

  • 已优化 成员统计算法从 O(N²) 降至 O(N)，大幅提升响应速度
  • 已优化 签到时间分散化，避免集中请求被风控
  • 已优化 死代码清理，减少冷启动时间
  • 已优化 DNS 解析绕过，解决 FC 无法访问学校域名问题
