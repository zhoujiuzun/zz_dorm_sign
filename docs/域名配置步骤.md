# 自定义域名配置步骤

## 📋 配置信息

- **函数名称**: sign
- **地域**: cn-beijing (华北2 北京)
- **当前临时域名**: https://sign-bprgxfyexe.cn-beijing.fcapp.run
- **目标自定义域名**: sign.zhztool.top

---

## 🔧 步骤 1：函数计算控制台绑定域名

1. 登录阿里云控制台：https://fc.console.aliyun.com
2. 选择地域：**华北2（北京）**
3. 在左侧菜单找到 **函数** → 点击函数名 **sign**
4. 点击 **触发器** 标签页
5. 点击 **域名管理** 或 **自定义域名**
6. 点击 **添加自定义域名**
7. 填写配置：
   - **域名**: `sign.zhztool.top`
   - **协议**: HTTP（后续可升级 HTTPS）
   - **路由配置**:
     - 路径: `/*`
     - 函数: `sign`
     - 版本: `LATEST`
8. 点击 **确定** 保存
9. **记下 CNAME 值**（类似 `sign-xxx.cn-beijing.fcapp.run`）

---

## 🌐 步骤 2：配置 DNS 解析

1. 登录阿里云控制台：https://dns.console.aliyun.com
2. 找到域名 **zhztool.top**，点击 **解析设置**
3. 点击 **添加记录**
4. 填写配置：
   - **记录类型**: CNAME
   - **主机记录**: `sign`
   - **解析线路**: 默认
   - **记录值**: 粘贴步骤 1 中记下的 CNAME 值（如 `sign-bprgxfyexe.cn-beijing.fcapp.run`）
   - **TTL**: 10 分钟（600 秒）
5. 点击 **确定** 保存

---

## ✅ 步骤 3：验证生效

等待 5-10 分钟后，在浏览器访问：

**http://sign.zhztool.top**

如果看到签到看板页面，说明配置成功！

---

## 🔒 步骤 4：配置 HTTPS（可选但推荐）

### 方式 1：阿里云免费 SSL 证书

1. 登录 SSL 证书控制台：https://yundun.console.aliyun.com/?p=cas
2. 点击 **免费证书** → **立即购买**（免费 DV 证书，1 年有效）
3. 购买后点击 **证书申请**，填写：
   - 域名：`sign.zhztool.top`
   - 验证方式：DNS（自动验证，因为域名在阿里云）
4. 提交后等待签发（通常 5-10 分钟）
5. 证书签发后，回到函数计算控制台：
   - 进入函数 **sign** → **触发器** → **域名管理**
   - 编辑 `sign.zhztool.top`
   - 协议改为 **HTTPS**
   - 选择刚才申请的 SSL 证书
   - 开启 **HTTP 强制跳转 HTTPS**
   - 保存

### 方式 2：Let's Encrypt（推荐，自动续期）

如果你想用自动续期的免费证书，可以使用阿里云 CDN + Let's Encrypt：

1. 开通 CDN 服务（按流量计费，小流量几乎免费）
2. 添加 CDN 域名加速 `sign.zhztool.top`
3. 源站地址填：`sign-bprgxfyexe.cn-beijing.fcapp.run`
4. 在 CDN 控制台申请免费证书（自动续期）
5. DNS 解析改为 CDN 的 CNAME

## 📝 注意事项

1. **备案要求**：
   - 你的域名 `zhztool.top` 如果用于公网访问，需要完成 ICP 备案
   - 如果只是内部使用（宿舍、学校），可以暂时不备案，但可能被限制访问

2. **小程序配置**：
   - 如果小程序要调用自定义域名的接口，需要在微信公众平台配置：
   - **开发** → **开发管理** → **服务器域名** → **request 合法域名**
   - 添加 `sign.zhztool.top`（需要 HTTPS）

3. **成本**：
   - 函数计算：免费额度足够（每月 100 万次调用 + 40 万 CU-秒）
   - DNS 解析：免费
   - SSL 证书：阿里云 DV 免费 1 年
   - 带宽流量：看板访问量小，几乎免费

## 🚨 故障排查

### 访问 sign.zhztool.top 显示 404

1. 检查 DNS 解析是否生效：
   ```bash
   nslookup sign.zhztool.top
   ```
   应该返回 CNAME 记录，指向 `sign-xxx.cn-beijing.fcapp.run`

2. 检查函数计算域名绑定：
   - 登录 FC 控制台确认自定义域名已添加

### 显示"域名未备案"

- 临时方案：访问原始域名 `https://sign-bprgxfyexe.cn-beijing.fcapp.run`
- 长期方案：完成 ICP 备案（阿里云备案服务，约 7-20 天）

### SSL 证书验证失败

- 确保域名 DNS 解析已生效
- 证书申请时选择"自动 DNS 验证"（域名在阿里云会自动添加验证记录）
